## 🎯 TABLA INTERACTIVA DE DECISIONES

Responde estas preguntas y sigue el flujo:

### Pregunta 1: ¿Cuánto tiempo tienes?
```
├─ ⏱️ 5 minutos     → VE A "RÁPIDO"
├─ ⏰ 30 minutos    → VE A "APRENDER"  
├─ 🕐 2 horas      → VE A "PROFUNDO"
└─ 📅 8+ horas     → VE A "EXPERTO"
```

### Pregunta 2: ¿Qué quieres hacer?
```
├─ Ejecutar programa        → RÁPIDO   → START_HERE → GUIA_RAPIDA
├─ Entender conceptos       → APRENDER → README → DIAGRAMAS
├─ Analizar el código       → PROFUNDO → ACTIVIDADES → CÓDIGO
└─ Convertirme en experto   → EXPERTO  → TODO + TESTS + EXTENSIONES
```

### Pregunta 3: ¿Cuál es tu nivel?
```
├─ Principiante  → APRENDER (Nivel 1-2)
├─ Intermedio    → PROFUNDO (Nivel 3-4)
└─ Avanzado      → EXPERTO (Nivel 5)
```
